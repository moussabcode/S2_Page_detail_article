Le role de dévollepeur

Le dévollepeur crée des applications. Il transforme un besoin en solution informatique

Réaliser l'application

Le développeur réalise l'application à partir du besoin. Il utilise des technologies comme HTML,CSS et JavaScript.
_Métier de dévoleppeur
  • Analyse le besoin: comprendre le projet
  • Réaliser l'application: écrire le code
  • Vérifier l'application: tester et corriger
  • Déployer l'application: mettre en ligne sur un serveur

Travalier en équipe

Le développeur travaille aussi avec équipe. La collaboration est importante pour réussir le projet.
